# Project KO

Read [AGENTS.md](AGENTS.md) for the repository rules,
[getting started](docs/getting-started.md) for setup and
[pko-layout](docs/pko-layout.md) for where the folders are — the App, the
Vault and the Workspace.

Complete project skills are available in `.claude/skills/`, including their
scripts and references. `.agents/skills/` is the maintained source shared with
Codex. Edit that source and run `npm run skills:sync` for a change intended for
both agents. Keep project instructions, workflows and knowledge here rather
than in global memory.
